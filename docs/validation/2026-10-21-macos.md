## Automated checks

- Rust formatting and `wasm32-wasip2` build.
- Deterministic bridge archive matches the committed SHA-256 on both hosts.
- 28 installer, update transaction and ZIP extraction unit tests.
- 26 checks against DCloud's real 4.87.0 runtime: UTS and both UVUE script styles,
  completions/details, cross-file and API definitions, hover, diagnostics, unsaved
  edits, incremental edits, CRLF, UTF-16 and shutdown.
- Empty-directory installation from the packaged bridge, including Chinese,
  emoji and spaces in the work path; validation before activation and cached launch.
- Reinstalling the same official version into a new directory, rejecting a broken
  checker, retaining both versions, rollback, pause/resume and managed launch.
- Windows grammar build; Mac grammars still need Zed dev-extension installation.

The Mac artifact `macos-arm64-reports` records `platform: darwin`, `arch: arm64`,
`pass: true` and `editorChecked: false`. No cache/IPC errors were found in its
captured bridge logs. The Windows local aggregate report is under the task work
directory at `uniapp-x-macos-prep/check-e7db35e5/report.json`.

An initial Windows run made the test project working directory 275 characters
long. Node could not spawn there (`ENOENT` / `ENOTCONN`). Shortening the outer
test directory fixed the harness; the complete fresh-install and lifecycle run
then passed. This does not establish support for arbitrary Windows cwd lengths.
